# 🎬 IMDb Top 1000 Movies Analysis

## 📌 Problem Statement
Analyze the IMDb Top 1000 movies dataset to understand what factors contribute to high-rated and successful movies.

---

## 📊 Dataset
- Source: IMDb Top 1000 dataset  
- Contains: movie ratings, genres, directors, revenue, runtime  

---

## 🧹 Data Cleaning
- Removed missing values  
- Converted data types  
- Handled inconsistent entries  

---

## 📈 Key Analysis & Insights

- ⭐ Movies with higher ratings are often concentrated in specific genres like Drama & Crime  
- 🎬 Certain directors consistently produce highly rated movies  
- 💰 Higher revenue is not always directly correlated with ratings  
- ⏱ Runtime has moderate impact on audience ratings  

---

---

## 💡 Conclusion
This analysis shows that movie success is influenced by multiple factors such as genre, director, and audience preferences rather than just revenue.
